# Diagnosing Bugs

A disciplined diagnosis loop for hard bugs and performance regressions: build a tight feedback loop first, then reproduce, minimise, hypothesise, instrument, fix, and regression-test.

Adapted from Matt Pocock's engineering diagnosing-bugs skill in [mattpocock/skills](https://github.com/mattpocock/skills/tree/main/skills/engineering/diagnosing-bugs).
