# Triage

Tracker-agnostic issue, PR, and inbox triage for shaping work into clear next states like `Needs Burooj`, `Blocked`, `Ready for agent`, `Parked`, `Canceled`, or `Done`.

Adapted from Matt Pocock's engineering triage workflow, especially the triage skill, agent brief, and out-of-scope notes in [mattpocock/skills](https://github.com/mattpocock/skills/tree/main/skills/engineering/triage).

The Codex/Claude skill entrypoint is [SKILL.md](SKILL.md).
